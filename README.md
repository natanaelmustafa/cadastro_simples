# Cadastro Simples

Aplicação web simples que demonstra um formulário de cadastro com validação básica e estilo responsivo. Feito para fins educacionais e como exemplo rápido de projeto em TypeScript, HTML e CSS.

## Funcionalidades

- Formulário de cadastro (nome, e-mail, senha)
- Validação básica dos campos
- Layout responsivo e estilização simples

## Tecnologias

- TypeScript
- HTML
- CSS

## Executando localmente

1. Clone o repositório:

   git clone https://github.com/natanaelmustafa/cadastro_simples.git

2. Instale as dependências:

   npm install

3. Inicie o projeto:

   npm run dev

   ou

   npm start
